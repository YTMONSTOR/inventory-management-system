# Склад — учёт товаров и списков выдачи

Веб-приложение для учёта товаров на складе: каталог с фотографиями, приход и выдача,
списки товаров к выдаче (вместо бумажных), история всех действий и отчёты в Excel и PDF.
Интерфейс полностью на русском языке, работает на компьютере, планшете и телефоне.

**Технологии:** Java 17, Spring Boot 3.3, Maven, PostgreSQL, HTML/CSS/JavaScript (без сборки фронтенда).

---

## 1. Что нужно установить (один раз)

| Программа | Где взять | Проверка |
|---|---|---|
| Java 17 или новее (JDK) | https://adoptium.net | `java -version` |
| Maven 3.9+ | https://maven.apache.org/download.cgi (или встроенный в IntelliJ IDEA) | `mvn -version` |
| PostgreSQL 14+ | https://www.postgresql.org/download/ | `psql --version` |

## 2. Создать базу данных (один раз)

Откройте **SQL Shell (psql)** или pgAdmin и выполните:

```sql
CREATE USER sklad WITH PASSWORD 'sklad';
CREATE DATABASE sklad OWNER sklad;
```

Таблицы создадутся автоматически при первом запуске программы. Существующие данные
при перезапуске **никогда не удаляются**.

> Хотите другой пароль? Задайте переменные окружения `SKLAD_DB_USER`, `SKLAD_DB_PASSWORD`, `SKLAD_DB_URL`
> или измените их в `src/main/resources/application.properties`.

## 3. Запуск

**Windows:** дважды щёлкните `start.bat`.
**macOS / Linux:** `./start.sh`.

Или вручную:

```bash
mvn spring-boot:run
```

Первый запуск скачивает библиотеки (нужен интернет, 2–5 минут). Затем откройте в браузере:

**http://localhost:8080**

Чтобы открыть склад с телефона или планшета в той же Wi-Fi сети, введите адрес
компьютера, например `http://192.168.1.10:8080` (адрес — команда `ipconfig` в Windows).

### Готовый файл для запуска без Maven

```bash
mvn clean package
java -jar target/sklad-1.0.0.jar
```

## 4. Где хранятся данные

* **База данных** — в PostgreSQL (база `sklad`).
* **Фотографии товаров** — папка `sklad-data/uploads` в домашней папке пользователя
  (например `C:\Users\Имя\sklad-data\uploads`). Папку можно изменить переменной `APP_DATA_DIR`.

### Резервная копия (делайте регулярно)

```bash
pg_dump -U sklad -d sklad -F c -f sklad-backup.dump
```

Плюс скопируйте папку `sklad-data`. Восстановление:

```bash
pg_restore -U sklad -d sklad --clean sklad-backup.dump
```

## 5. Как пользоваться

1. **Товары → Добавить товар.** Название, цена, сколько сейчас на складе, фото. Код товара
   присваивается автоматически (TV-00001…), но его можно указать свой. Штрихкод можно отсканировать сканером.
2. **Склад.** Кнопки «Приход» (товар поступил), «Выдать» (выдача без списка) и «Инвентаризация»
   (исправить остаток по факту). Каждое действие записывается в журнал.
3. **Списки к выдаче → Новый список.** Найдите товары, нажмите на них, укажите количество,
   сохраните. Сразу видно цену, остаток на складе и общую сумму. Можно сохранить черновик.
4. **Выдача по списку.** Откройте список → «Выдать товары». Можно выдать всё или только часть.
   Остаток на складе уменьшается автоматически, а список становится «Выдан частично»,
   пока не будет выдано всё. Статус «Выдан полностью» ставится **только** когда выдана каждая позиция.
5. **Печать.** В списке — кнопка «Печать» (с графами «Выдал / Получил») или скачивание PDF/Excel.
6. **История** — все действия с датой, временем и фильтрами. **Отчёты** — остатки, стоимость склада,
   выданные товары, поступления, ожидающие выдачи, заканчивающиеся товары; Excel и PDF.

Клавиша `/` — быстрый поиск товара из любого места.

## 6. Надёжность учёта

* Остаток меняется только через операции склада; каждое изменение — в одной транзакции
  с блокировкой строки товара (два человека не «перевыдадут» один товар одновременно).
* База данных сама запрещает отрицательный остаток (`CHECK quantity >= 0`) и выдачу по
  списку больше, чем в нём указано (`CHECK issued_qty <= required_qty`).
* Удалённый товар скрывается из каталога, но его история сохраняется в отчётах.
  Товар из незавершённого списка удалить нельзя.
* Список, по которому уже выдавали товар, нельзя удалить — только отменить
  (выданное остаётся выданным).

## 7. Устройство проекта

```
src/main/java/org/example
├── WarehouseApplication.java      запуск
├── domain/                        сущности (Entities), статусы, ошибки
├── repository/                    SQL-запросы (Spring JDBC)
├── service/                       бизнес-логика: склад, списки, отчёты, Excel, PDF
└── web/                           REST API и обработка ошибок
src/main/resources
├── schema.sql                     схема PostgreSQL (таблицы, ограничения, индексы)
├── application.properties         настройки
├── fonts/                         шрифт DejaVu Sans для кириллицы в PDF
└── static/                        интерфейс (index.html, css, js)
```

Таблицы: `users`, `categories`, `products`, `product_images`, `inventory_movements`,
`product_lists`, `product_list_items`, `issue_records`, `activity_logs`, `app_settings`.

Вход по паролю не нужен: программа рассчитана на запуск на компьютере склада
в доверенной сети. Если сайт будет доступен из интернета, сначала нужно добавить вход по паролю.

## 8. Если что-то не работает

| Сообщение | Что делать |
|---|---|
| `Connection refused` / `password authentication failed` | PostgreSQL не запущен или неверный пароль — см. раздел 2 |
| `Port 8080 was already in use` | Запустите с другим портом: `set APP_PORT=8081` (Windows) и снова `start.bat` |
| В PDF вместо букв квадраты | Проверьте, что папка `src/main/resources/fonts` на месте |

## 9. Список из сообщения Telegram / WhatsApp (встроенный ИИ)

На странице **Списки к выдаче → Новый список** вверху есть блок «Вставить список из сообщения».
Скопируйте сообщение клиента, вставьте и нажмите **«Анализировать»**.

Разбор делает **встроенный мини-ИИ прямо в программе**: без интернета, без ключей, бесплатно.
Он понимает:
* количество рядом с названием: «Буква 3», «3 буква», «буква х3», «буква 3шт», «5 та», «2 dona», «10 кг»;
* размер в названии отдельно от количества: «Труба 25 мм 6» → труба 25 мм, 6 шт; «кабель 3х2,5 100м»;
* опечатки и сокращения: «малако», «хлеп», «мол»; окончания: «яйца», «саморезы»;
* латиницу и узбекский: «sut», «non», «shakar», «tuxum», «guruch»;
* несколько товаров в строке: «молоко 5, хлеб 2» или «молоко 5 хлеб 2»;
* приветствия пропускает, имя клиента («это Ойбек», «мен Азиз») подставляет в список.

Результат **не сохраняется сам**. Зелёные строки — найдено точно, жёлтые — «проверьте»
(например, в каталоге два вида масла), красные — товара нет в каталоге. Товар можно поменять,
количество исправить, строку убрать. Новые товары не создаются. Сохраняет только кнопка «Сохранить список».

**Он учится.** Когда вы сами выбираете товар для слова из сообщения (например, для «sut» —
«Молоко 0,5 л»), программа запоминает это (таблица `product_aliases`), и в следующий раз
находит такой товар сразу. Чем дольше пользуетесь — тем точнее.

Код разбора — `src/main/java/org/example/ai/SmartTextParser.java`. Узбекские и разговорные слова
можно дополнить в словаре `SYNONYMS` в начале файла.
